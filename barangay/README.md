# wah

Build a complete, polished Barangay Service Request and Community Community Platform for Barangay Balibago, Angeles City, Pampanga, Philippines from scratch.

The platform should combine three core experiences:

A modern public-facing landing page

A resident community platform where people can view and share community updates, suggestions, announcements, and discussions

A barangay service request and community issue reporting system

The goal is to create something that feels like a modern digital community hub for Barangay Balibago rather than a traditional government website.

The experience should be approachable, visually engaging, interactive, and easy to use while still being trustworthy and appropriate for a public-service platform.
